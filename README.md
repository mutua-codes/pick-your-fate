# Pick Your Fate 🎁

A fun and interactive box-picking game built with Next.js, TypeScript, Bootstrap 5, and CSS.

## About
Pick one of eight mystery boxes and discover your unexpected destiny! Each box reveals a funny and surprising outcome.

## Technologies
- Next.js
- TypeScript
- Bootstrap 5
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features
- 8 interactive mystery boxes.
- Random funny outcomes.
- Box-opening animations.
- Play Again functionality.
- Responsive design.
